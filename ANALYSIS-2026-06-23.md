## 1. Executive summary

qsearch is a **well-built passive search aggregator** with a genuinely differentiated core: multi-engine provenance + a persistent local trust corpus. The search foundation is solid (mature priority routing, real SSRF guard, loopback hardening, graceful backend fallback). The gaps are **not** in the search idea — they are in (a) a handful of real correctness bugs, (b) the trust formula being under-finished relative to its own spec, (c) the absence of production-ops infrastructure (which becomes load-bearing the moment the service leaves loopback), and (d) quality machinery (Layer 8 gate, rerank) that ships disabled and has never been empirically validated.

Prior audits already framed this as **"5-star search foundation, 2-star agentic harness"** (2026-06-07) — and that boundary is *intentional and correct*: query refinement / multi-turn verification belongs in the agent framework, not in qsearch core. This report does **not** try to close that gap; it strengthens what qsearch already is.

**Highest-leverage work, in order, given the LAN/VPS deploy intent:**
1. **Tier 0 (gating):** auth + rate-limit + request body-size limit before *any* non-loopback exposure. Without these, exposing the service re-opens the original BLOCK findings (zero-auth `/index` reads the filesystem into a searchable corpus; unbounded POST bodies OOM the process).
2. **Tier 1 (quick-wins):** fix the `topByTrust` data-integrity bug, add per-query timeouts, de-collide auto-labels (silent data loss). Small, safe, high-value regardless of deployment.
3. **Tier 2 (trust formula):** unify the three divergent formula copies, add recency decay, gate ultra-broad on trust. Strengthens the actual differentiator vs Tavily/Exa.
4. **Tier 3–5:** reliability (graceful shutdown, structured logging), quality validation (needs *data*, not just code), and DX/maintainability (route table, OpenAPI, MCP parity).

## 2. How qsearch works

Node.js (≥20, raw `node:http`, ESM, no web framework) meta-search layer. End-to-end flow:

1. **Fan-out + routing** — `src/sweep/router.js`, `src/sweep/runner.js`. `parseQueriesText()` parses `label|query|priority|domain` lines → `createSweepRouter()` → `runSweep()` runs queries concurrently behind a semaphore (`MAX_PARALLEL=6`, env `SWEEP_CONCURRENCY`). Priority tiers, cost-ascending: `ultra-broad` (corpus-only, $0) → `broad` (SearXNG, $0) → `focused` (Brave web) → `critical` (Brave web + LLM Context). Domain routing: `general` / `scholarly` (arxiv + PubMed + Semantic Scholar) / `ru` (Yandex if configured, else SearXNG `language=ru-RU`).
2. **Dedup + attribution** — URLs deduped; `engines[]` merged into a Set, so a URL found by Brave + SearXNG carries `engines=[brave, searxng]`, `engine_count=2`. That count *is* the trust signal.
3. **Persistence** — `src/corpus/meilisearch.js` (full-text + filtering) and `src/corpus/qdrant.js` (vectors). Upsert by URL with `engines[]` union + `appeared_in_sweeps[]` history append. Trust = `log(sweep_count+1) × engine_diversity × topic_diversity`.
4. **Optional enrichment** — local-LLM cleaning (Ollama `qwen2.5:7b`, `src/clean/`), 3-stage rerank (`src/rerank/`: embedding → LLM-scoring → composite quality gate). **Layer 8 quality gate + rerank are OFF by default.**
5. **Caching / economy** — `src/cache.js` SQLite memcache, per-endpoint TTL (web 7d / news 1d / context 30d), economy report vs an all-Brave baseline.
6. **Two surfaces** — REST `:8080` (`src/server.js`, ~1920 lines, ~27 endpoints, if/else dispatcher) + MCP-over-HTTP `:8081` (`src/mcp-http.js`, Zod-validated, 8 tools wrapping REST).
7. **Security** — loopback bind by default (`server.listen(PORT, process.env.QSEARCH_BIND || '127.0.0.1', …)`, `server.js:1879`); SSRF guard (`src/fetch/html.js`); filesystem path boundary (`QSEARCH_DATA_ROOTS` + `SENSITIVE_FILE_RE`, `server.js:85-97`).

### Confirmed strengths (don't break these)

| Strength | Evidence |
|---|---|
| Mature priority/domain routing with clean fallbacks (broad→SearXNG+Brave; critical layers LLM Context as soft-fail; ru auto-detects Cyrillic) | `src/sweep/router.js` |
| Multi-engine dedup with `engines[]` union on URL collision | `runner.js:119-123`, `meilisearch.js:55` |
| **Real SSRF guard** — DNS resolution, 10 private/loopback/metadata ranges, re-validated on *every* redirect hop (manual redirect loop), 2MB byte cap, timeout | `src/fetch/html.js:18-108`, tests in `test/unit/fetch/ssrf.test.js` |
| Loopback hardening + path guards + Meili-key refusal when non-loopback | `server.js:62-71, 85-97, 1879` |
| Engine-health canary surfaces silent SearXNG degradation at startup and via `/health?deep=1` | `server.js:748-814`, `searxng.probe()` |
| Lean dependency surface — 7 direct deps, no Express/framework | `package.json` |

## 3. Weaknesses — 6 themes (with evidence)

### Theme 1 — Data consistency & correctness
- **`topByTrust()` hardcodes `topic_diversity=1` for non-`trust` sorts** — `src/corpus/meilisearch.js:294-301`. The `sort=trust` branch computes it correctly (L268-270); the `engine_count`/`sweep_count`/`first_seen` branch returns `topic_diversity: 1`. The *same URL* returns a ~10× lower `trust_score` depending on `?sort=`. Violates the formula contract. **(confirmed)**
- **No per-query timeout** — `src/sweep/runner.js:112-136`. Backends have internal timeouts (Brave ~10s, Yandex ~15s) but no per-query deadline wraps the semaphore task. One slow query holds a slot; pathological sweeps balloon to minutes. **(confirmed)**
- **Auto-label collision = silent data loss** — `parseQueriesText()` assigns `q01, q02…` to bare lines without checking against explicit labels. A collision overwrites an entry in the `Map<label, result>`. **(confirmed)**
- **Zero-result retry has no backoff** — `runner.js:147-150` uses fixed `600 + random*400` ms jitter then retries the *same tier*. A 429 will likely fail again. **(confirmed)**

### Theme 2 — Trust formula maturity (the core differentiator)
- **Formula exists in 3 divergent copies in one file** — `meilisearch.js:230` (`trustScore`, full formula), `:270` (`topByTrust` sort=trust, recomputed from `appeared_in_sweeps`), `:297` (other sorts, `log(sweeps+1) × engine_count` — **no `topic_diversity`**). Should be one helper. **(confirmed)**
- **No recency decay** — `meilisearch.js:230`. A URL last seen in 2024 scores identically to one seen in June 2026 at equal sweep/engine/topic counts. Stale entries are indistinguishable from fresh — and ultra-broad serves them as "current." **(confirmed)**
- **Ultra-broad gate ignores trust** — `corpusLookup()` (`meilisearch.js:107-145`) accepts on `minHits≥3` and `avgScore≥0.55` (Meilisearch BM25) only, **not `trust_score`**. A high-BM25 but single-engine/single-sweep URL short-circuits a paid sweep. Per `TRUST_MESH.md`, trust should gate acceptance. **(confirmed)**
- **`appeared_in_sweeps[]` grows unbounded per document** — `meilisearch.js:65` appends one entry per sweep, forever. A URL seen in 100 sweeps stores 100 entries; `topByTrust` sort=trust loads up to 5000 such docs in memory (`:258`). Storage + memory scaling concern. **(firsthand)**
- **`topic_diversity` from brittle heuristic** — `sweep_label.split('_')[0]` (`:217, :268`). Labels with hyphens/spaces silently degrade the topic signal. **(confirmed)**

### Theme 3 — Production hardening (load-bearing once non-loopback)
- **No authentication on any endpoint** — `server.js:1747-1871`, `mcp-http.js` (`CORS: *`). x402 middleware is a stub. Loopback bind is the *only* thing protecting 27 endpoints today. **(confirmed)**
- **No rate limiting** — DoS surface on `/sweep_context` (20 external fetches/req), `/index` (filesystem glob), `/search` (paid backend calls). **(confirmed)**
- **No request body size limit** — `readBody()` (`server.js:147-154`) buffers the entire stream with no `Content-Length`/byte cap → OOM DoS on every POST. **(confirmed)**
- **No graceful shutdown** — `server.js:1873-1920` has no SIGTERM/SIGINT handler; SIGTERM drops in-flight `/sweep`/`/index`/`/sweep_context`. **(confirmed)**
- **No global error handlers** — no `process.on('uncaughtException'|'unhandledRejection')`; a stray throw/rejection crashes silently. **(confirmed)**
- **No structured logging** — ~102 scattered `console.log` calls, no correlation IDs, no way to trace one `/sweep` across `:8080`↔`:8081`. **(confirmed)**
- **`/health` doesn't gate on Meili/Qdrant** — returns 200 even when corpus backends are down and `/search` would fail. **(partial: corpusStatus is tracked at `server.js:135-144`, but `/health` liveness doesn't 503 on it)**
- **6+ transitive `npm audit` vulns** — fast-uri, hono, brace-expansion, qs, undici (moderate/high). **(confirmed)**

### Theme 4 — Quality unvalidated
- **Layer 8 gate + rerank OFF by default, never calibrated** — `server.js:1884-1889`, `quality_gate.js:13-14`. Weights `emb 0.4 / auth 0.3 / llm 0.2 / trust 0.1` and threshold `0.4` are untested on real corpus; the "~72% rejection" target in `ARCHITECTURE.md` is aspirational. **(confirmed)**
- **Zero rerank-quality benchmarks** — no NDCG/MRR test asserts `embedding_rerank`/`llm_rerank` actually improve ordering; `nomic-embed-text` is weak on domain tasks and unbenchmarked vs alternatives. **(confirmed)**
- **Trust under-weighted in the gate** — authority (static `.gov`/`.edu` heuristics) gets 0.3 while trust (the differentiator) gets 0.1. **(confirmed)**
- **Arbitrary trust normalization** — `quality_gate.js:86` saturates trust at `2.0` with no corpus-percentile basis. **(confirmed)**

### Theme 5 — Observability & DX
- **Monolithic if/else dispatcher** — `server.js:1747-1871`, ~27 endpoints, order-dependent, no introspection, blocks OpenAPI generation. **(confirmed)**
- **Inconsistent error envelopes** — `{error}` vs `{error,status,detail}` vs header-only across handlers. **(confirmed)**
- **No OpenAPI schema** — integrators reverse-engineer endpoints from source. **(confirmed)**
- **MCP↔REST parity gaps** — `web_search` omits `corpus_first`/`corpus_only`; `sweep` doesn't document priority/domain. `src/mcp.js`. **(partial)**

### Theme 6 — Agentic verification gap (intentional boundary)
- One-shot, deterministic; no analyze→follow-up loop, contradiction detection, or claim attribution. **Position: keep qsearch passive.** Heavy verification stays in the agent framework (`brave_sweep.py`, Claude Code). The only in-scope nibble is *opt-in* lightweight cross-query contradiction flagging — and even that is `[needs-sprint]` because it touches the passive-design boundary.

## 4. Prioritized roadmap

Ordering reflects the LAN/VPS deploy intent: **exposing beyond loopback without Tier 0 re-opens the original BLOCK findings.** Each item: impact/effort + locked-flag + file:line.

### Tier 0 — GATING before any LAN/VPS exposure
| Item | Impact | Effort | Flag | Where |
|---|---|---|---|---|
| **Auth layer** (bearer token / IP allowlist); required when `QSEARCH_BIND≠loopback` | high | M | `[locked-OK]` | new `src/middleware/auth.js`, wire before routing |
| **Per-endpoint rate limit** (429 + Retry-After, in-memory token bucket): `/index` 10/min, `/sweep_context` 20/min, `/search` 100/min, `/sweep` 30/min | high | M | `[locked-OK]` | new `src/middleware/ratelimit.js`, `server.js` |
| **Request body size limit** (413 over cap, ~1-10MB) | high | **S** | `[locked-OK]` | `server.js:147-154` (`readBody`) |
| **`npm audit fix`** + re-run `test:all` | medium | S | `[locked-OK]` | `package.json`, `package-lock.json` |
| **Per-service health** (ping Meili/Qdrant, 503 if down) | medium | S | `[locked-OK]` | `server.js` `handleHealth` |

> **Why Tier 0 is gating, concretely:** today loopback bind is the *sole* protection. The moment `QSEARCH_BIND` is non-loopback, an unauthenticated LAN/internet peer can `POST /index` a glob, wait for async indexing, then `GET /search` for the indexed content — the original critical chain. Auth + rate-limit + body-cap must land *before* the bind changes.

### Tier 1 — Correctness quick-wins (safe anytime, ~1 sitting)
- **Fix `topByTrust` `topic_diversity` bug** — extract topic calc into a helper, apply to all sort branches. high / **S** / `[locked-OK]` / `meilisearch.js:294-301`.
- **Per-query timeout** — `Promise.race` + AbortController; `QSEARCH_SWEEP_QUERY_TIMEOUT_MS` (default 8000). high / S→M / `[locked-OK]` / `runner.js:112-136`.
- **De-collide auto-labels** — Set check / auto-increment in `parseQueriesText`. medium / S / `[locked-OK]` / `runner.js`.
- **Exp-backoff for zero-result retry** (1s/2s/4s, or tier-downgrade). medium / S / `[locked-OK]` / `runner.js:147-150`.
- **Log ultra-broad fall-through reason** (hits/score/age). medium / S / `[locked-OK]` / `router.js`.

### Tier 2 — Trust formula (strengthens the differentiator)
- **Unify the 3 formula copies** into one helper. medium / S / `[locked-OK]` / `meilisearch.js:230,270,297`.
- **Recency decay** — `× exp(-k · days_since_last_seen)`, k≈90-day half-life. high / M / `[locked-OK]` / `meilisearch.js`. ⚠️ k is a guess — analyze corpus age distribution before prod tuning.
- **Trust gate in ultra-broad** — `QSEARCH_ULTRA_BROAD_MIN_TRUST`≈2.0. high / M / **`[needs-sprint]`** (decision: trust as sufficiency-gate vs rerank-only signal touches ultra-broad design) / `corpusLookup()`.
- **Percentile trust normalization** — saturate at p90, not fixed 2.0. medium / M / `[locked-OK]` / `quality_gate.js:86` (needs 1000+ URL corpus data).
- **(Optional) cap `appeared_in_sweeps[]` growth** — keep last-N + counters instead of unbounded append. medium / M / `[locked-OK]` / `meilisearch.js:65`.

### Tier 3 — Production reliability (VPS uptime)
- **Graceful shutdown** (SIGTERM/SIGINT → `server.close` + ≤30s drain + cache flush). high / **S** / `[locked-OK]` / after `server.listen`.
- **Global handlers** (`uncaughtException`/`unhandledRejection`). medium / S / `[locked-OK]`.
- **Structured logging** (JSON + correlation IDs across `:8080`↔`:8081`). medium / M / `[locked-OK]` / new `src/logger.js`.

### Tier 4 — Quality validation (unblocks "shipped" claims; needs DATA)
- **Empirical Layer 8 dogfood** — 10+ sprints, 50+ URL golden set, grid-search weights/threshold, document precision/recall/F1 curve. high / **L** / `[locked-OK]` / new `test/integration/quality_gate_eval.js`.
- **NDCG rerank benchmark** — no-rerank vs random vs embedding on 20 ground-truth queries; if <5% gain, swap nomic-embed-text for BGE/E5. high / M / `[locked-OK]` / new `test/integration/rerank_benchmark.js`.
- **Re-weight gate** (trust 0.1→0.25, auth 0.3→0.15) — **only after dogfood data**. medium / S / `[locked-OK]` / `quality_gate.js:13`.

### Tier 5 — DX & maintainability
- **Route-table refactor** (replace if/else with `{method,pattern,handler}` registry). high / M / `[locked-OK]` / `server.js:1747-1871`. Unblocks OpenAPI.
- **Standard error envelope** (`{error,status?,detail?,request_id?}` + `sendError` helper). medium / M / `[locked-OK]`.
- **OpenAPI 3.0** (`public/openapi.json` + `GET /openapi.json`). medium / M / `[locked-OK]`.
- **MCP↔REST parity** (expose `corpus_first`/`corpus_only`, document priority/domain). low / S / `[locked-OK]` / `src/mcp.js`.
- **Integration tests for security endpoints** (`/index` rejects `.env`, `/sweep_context` rejects loopback, body-limit enforced). high / M / `[locked-OK]` / new `test/integration/security.test.js`.
- **Claim-level attribution** for `cleaned_markdown` (`claims:[{text,source_url,snippet_index}]`). medium / M / `[locked-OK]` / `src/clean/ollama.js`, `src/sweep_context.js`.
- **Crawl4AI pre-flight + output schema validation** (avoid silent 60s timeout / malformed-doc indexing). low-medium / S / `[locked-OK]` / `src/crawl/crawl4ai.js`.

## 5. Do NOT do (traps + locked-arch boundary)

- **Do not re-litigate locked layers 1–10** (Meilisearch≠Tantivy, Yjs≠Tether, SQLite+ed25519≠Hypercore, MCP+A2A, off-chain Sybil) without a research sprint + decision-log entry.
- **Do not add heavy agentic verification to core** (multi-turn refinement, adversarial claim-checking). It belongs in the agent framework. Keep qsearch passive. Lightweight contradiction flagging is the *only* candidate, and it is `[needs-sprint]`.
- **Do not ship recency decay (k) or re-weighted gate without dogfood data.** k=0.0077 (90-day half-life) and the proposed weights are guesses; tune against the real corpus first.
- **Do not enable Layer 8 in CI** until the dogfood corpus reaches 500+ URLs and weights/threshold are tuned — it would otherwise gate CI on untuned numbers.
- **Do not make auth optional when non-loopback.** If exposed, auth is mandatory (bearer OR IP allowlist), not a toggle.
- **Do not swap nomic-embed-text before the NDCG benchmark proves it weak** — avoid churn.

## Appendix B — How to verify each fix when implemented (later)
- **topic_diversity fix:** `/corpus/top?sort=engine_count` and `?sort=trust` must return the *same* `trust_score` for the same URL.
- **Body limit:** POST > cap → 413.
- **Per-query timeout:** sweep with an artificially slow backend completes in ≤ N·timeout, not unbounded.
- **Auth:** with `QSEARCH_BIND` non-loopback and no key → 401; valid key → 200; loopback → no auth required.
- **Recency decay:** an old URL and a fresh URL with identical sweep/engine/topic counts must produce different `trust_score` (fresh > old).
- **Ultra-broad trust gate:** a single-engine/single-sweep corpus hit must *not* satisfy sufficiency; the query must fall through to broad.
