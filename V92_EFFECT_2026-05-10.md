**Observations:**

1. **Tier routing operational** — 56 broad → qsearch SearXNG (FREE, $0). 73 brave web + 10 context endpoint = ~$0.005×73 + $0.01×10 = **~$0.46/sprint** vs hypothetical pure Brave: 117 × $0.005 = $0.58 (если без context) или $1.17 (если +50% получили бы context). Saving ~20-60% per sprint by tiering.
2. **Auto-context для critical** — 10 critical queries автоматически получили LLM Context endpoint (визуально в файлах `*_context.json`).
3. **Dedup work** — 192 duplicate results removed. Quality average 5.01 (по шкале brave_sweep).
4. **Parallel cap** — 20 (по plan QPS).
5. **27 warnings в parsed_snippets** — отдельный gap, нужно посмотреть содержимое (вероятно encoding или пропущенные description fields).
