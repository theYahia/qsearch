# Марафон 2026-06-07 — Truthlode Bench: MVP → publishable v1

> Итог вечернего марафона (записан 2026-06-08). Контекст: qsearch backend-as-product был RED → пивот в RaaS → уточнён в **открытый бенчмарк честности цитат для AI deep-research агентов** (recognition-first wedge). Это слой 1 продукта **Truthlode** (см. [README](./README.md)).

## Что делали (milestone'ы A2 → v7 за вечер)
- **A2** — PDF-парсер (pdfjs-dist) + Crawl4AI → починили ~40% Error rate в verifier.
- **A3** — фильтр nav/boilerplate в excerpt'ах + `agreement.js` (judge-vs-human), cache v4.
- **A4** — расширение датасета: 2 новых legal-промпта (qualified immunity + fair use) через Claude DR и Gemini DR.
- **Bake-off** — noncompete v5 → multi-topic (3 темы × 2 агента); reverted over-aggressive prose filter; cache v5.
- **extract.js** → cross-topic aggregation (273 цитаты: 154 Gemini / 119 Claude).
- **Gold set** — `build_gold.mjs` → 55-citation stratified labels.
- **Judge** — Ollama qwen2.5:7b → **DeepSeek (deepseek-chat, temp 0)** через `DEEPSEEK_API_KEY`.
- **Verifier** — убрали embedding rerank → **full-document lexical** подход, cache v7.

## Что получили (outputs)
- **Рабочий v1-пайплайн:** `verifier.js` + `fetch_content.js` (pdfjs + Crawl4AI + dead→Fabricated) + `harness.js` + `extract.js` + `agreement.js` + `build_gold.mjs`. (теперь в `bench/`)
- **Канонический leaderboard** (`bench/out/all/`): **Claude DR 83.7%** support / **2.3%** fabrication (86 cites) vs **Gemini 3.1 Pro DR 77.9%** / **0.0%** (113 cites), 3 legal topics.
- **Judge-human agreement 87.3% binary / 83.6% exact** на 55-citation gold set — бьёт published CiteGuard baseline 68%.
- Все judge-vs-human расхождения **консервативны** (судья недооценивает, никогда не переоценивает) → идеальный failure mode для trust-продукта.
- Известное ограничение: ~27% Error от hard Cloudflare-блоков (icemiller.com, justia.com) → отложено на residential proxies.
- Market intel: gap $100–5000 «done-for-you cited reports» пуст (3 независимых прохода); verdict **GO-FOCUSED** на Angle A.
